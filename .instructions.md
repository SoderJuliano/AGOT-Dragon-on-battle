# CK3/AGOT Mod — Regras para criar e editar Decisões

## Localização obrigatória por decisão

Para cada decisão `foo_bar_decision`, as chaves `.yml` necessárias são:

| Chave | Uso |
|---|---|
| `foo_bar_decision` | Título na lista de decisões |
| `foo_bar_decision_desc` | Texto descritivo da janela |
| `foo_bar_decision_tooltip` | Tooltip ao passar o mouse |
| `foo_bar_decision_confirm` | **Texto do botão de confirmar** — sem isso o jogo exibe o nome da variável crua |
| Cada `text = foo_key` em `custom_description` | Precisa de entrada própria no `.yml` |

## Controle "fabricar só 1 vez" (sem cooldown)

- Use `any_owned_artifact { has_variable = meu_artefato }` dentro de **`is_shown`** para ocultar a decisão enquanto o artefato existir.
- **Não** ponha esse check dentro de `is_valid` — o jogo tenta renderizar o trigger como texto e exibe o nome bruto da variável.
- Remova `cooldown = { years = X }` quando o `is_shown` já controla a disponibilidade.

```pdx
is_shown = {
    is_ai = no
    NOT = {
        any_owned_artifact = { has_variable = meu_artefato }
    }
}
```

## Custo com ouro + prestígio

```pdx
cost = {
    gold   = 500
    prestige = 500
}

is_valid_showing_failures_only = {
    custom_description = {
        text = foo_not_enough_gold
        gold >= 500
    }
    custom_description = {
        text = foo_not_enough_prestige
        prestige >= 500
    }
}
```

## Portrait modifier — colocar TODOS os acessórios no mesmo bloco

**Nunca** coloque o headgear em um grupo `headgear_armor` separado do corpo. Cada grupo faz sua própria seleção independente (`weighted_random`). Se o grupo do headgear perder a seleção para o AGOT, o capacete não muda mesmo que o corpo mude.

**Correto — os 3 genes no mesmo bloco dentro de `clothes_armor`:**
```pdx
clothes_armor = {
    usage = game
    selection_behavior = weighted_random
    priority = 4

    dob_clothing_meu_artefato = {
        dna_modifiers = {
            accessory = { mode = add; gene = clothes;  template = agot_all_armors; accessory = dob_meu_body    }
            accessory = { mode = add; gene = legwear;  template = agot_all_legwear; accessory = dob_meu_legwear }
            accessory = { mode = add; gene = headgear; template = agot_all_armors; accessory = dob_meu_headgear }
        }
        weight = { base = 0; modifier = { add = agot_artifact_portrait_modifier; exists = this; agot_has_artifact_equipped = { ARTIFACT_VARIABLE = meu_var } } }
    }
}
```

**Errado — headgear em grupo separado:**
```pdx
# ← NÃO FAZER: headgear_armor { ... } separado
# O grupo headgear_armor faz seleção independente e pode perder para o AGOT
# resultando no capacete antigo permanecendo mesmo com o artefato equipado.
```

O CK3 permite que um único entry modifique qualquer gene (`clothes`, `legwear`, `headgear`) independentemente do nome do grupo em que está. Use `template = agot_all_armors` para headgear customizado de armadura (o `agot_most_headgears` só cobre headgears registrados nas gene tables do AGOT).

Não adicione `portrait_wear_armor_trigger` nem `portrait_wear_helmet_trigger` ao bloco `clothes_armor` (corpo/legwear). Essas triggers só retornam `yes` durante batalha ativa — a armadura nunca aparece no retrato normal do personagem.

Para headgear que deve aparecer APENAS em batalha, use um bloco `headgear_armor` separado COM `portrait_wear_helmet_trigger = yes`. O headgear fora de batalha simplesmente não aparece (comportamento normal do jogo).

**Peso dos modifiers:** Use `add = 1000000` para garantir vitória sobre todos os mods concorrentes (AGOT usa ~500; mods como Armor of the Kingsguard podem usar valores maiores).

**Correto — corpo sempre visível, capacete só em batalha:**
```pdx
clothes_armor = {
    usage = game
    selection_behavior = weighted_random
    priority = 4
    meu_artefato_body = {
        dna_modifiers = {
            accessory = { mode = add; gene = clothes;  template = agot_all_armors;  accessory = meu_body  }
            accessory = { mode = add; gene = legwear;  template = agot_all_legwear; accessory = meu_legwear }
        }
        weight = { base = 0; modifier = { add = 1000000; exists = this; agot_has_artifact_equipped = { ARTIFACT_VARIABLE = meu_artefato } } }
    }
}
headgear_armor = {
    usage = game
    selection_behavior = weighted_random
    priority = 4
    meu_artefato_headgear = {
        dna_modifiers = {
            accessory = { mode = add; gene = headgear; template = agot_most_headgears; accessory = meu_headgear }
        }
        weight = { base = 0; modifier = { add = 1000000; exists = this; portrait_wear_helmet_trigger = yes; agot_has_artifact_equipped = { ARTIFACT_VARIABLE = meu_artefato } } }
    }
}
```

**Errado:**
```pdx
modifier = {
    add = agot_artifact_portrait_modifier
    exists = this
    portrait_wear_armor_trigger = yes   # ← bloqueia fora de batalha
    agot_has_artifact_equipped = { ARTIFACT_VARIABLE = meu_artefato }
}
```

## Template do artefato — único vs por personagem

- `unique = no` → cada personagem pode fabricar o seu próprio.
- `unique = yes` → apenas um existe no mundo inteiro (o jogo impede duplicatas).

## Checklist antes de testar no jogo

- [ ] Chave `_decision_confirm` existe no `.yml`
- [ ] Nenhum trigger nu dentro de `is_valid` que seria renderizado como texto
- [ ] `is_shown` oculta a decisão quando o artefato já existe
- [ ] Portrait modifier sem `portrait_wear_*_trigger` se quiser aparecer fora de batalha
- [ ] Todas as chaves de `custom_description { text = ... }` têm localização correspondente
- [ ] O arquivo `.yml` começa com BOM UTF-8 (use o `!FIX_ENCODING_UTF8_BOM.bat` se necessário)
